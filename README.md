# Tasamify / Tasami Group

Production site lives in **`site/`** (Next.js App Router).

The previous Vite SPA sources remain in the repo root for reference and are not deleted.

## Quick start

```bash
cd site
cp .env.example .env.local
npm install
npm run dev
```

From repo root:

```bash
npm run dev
npm run build
npm run start
```
